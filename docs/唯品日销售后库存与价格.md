# 唯品日销售后、可售库存与价格

`vip_daily_sales` 及年度分表新增 16 列，来源为影刀导出的唯品商品明细。以日期、商品 ID、尺码 ID 匹配现有日销行。

| Excel 表头 | 数据库字段 |
| --- | --- |
| 退货件数、拒收件数、拒退件数、换货件数 | `return_quantity`、`reject_quantity`、`reject_return_quantity`、`exchange_quantity` |
| 退货金额、拒收金额、拒退金额、换货金额 | `return_amount`、`reject_amount`、`reject_return_amount`、`exchange_amount` |
| 退货率(退货件数/销售量)、拒收率(拒收件数/销售量)、拒退率、换货率(换货件数/销售量) | `return_rate`、`reject_rate`、`reject_return_rate`、`exchange_rate` |
| 可售库存 | `available_stock` |
| 最低市场价、最低到手价、最低唯品价 | `lowest_market_price`、`lowest_take_home_price`、`lowest_vip_price` |

比率按小数存储，如 `33.33%` 存为 `0.3333`。沿用 Excel 的售后口径，包括超过 100% 的有效比率。空白保留为 `NULL`。可售库存与在售库存分别存储。

从 `backend` 目录用项目 Python 运行以下命令。暂存目录每批使用一个新路径，报表按 `YYYY-MM-DD.xlsx` 命名。

```powershell
python -m scripts.backfill_vip_daily_detail extract --source-dir '\\Hede\运营组资料\影刀\唯品商品明细' --stage-dir ../outputs/vip_daily_detail_batch
python -m scripts.backfill_vip_daily_detail check --stage-dir ../outputs/vip_daily_detail_batch
python -m scripts.backfill_vip_daily_detail apply --stage-dir ../outputs/vip_daily_detail_batch
```

`check` 核对来源条数与数据库匹配条数；`apply` 可重复运行，逐日更新并核验这 16 列。若某个商品尺码还没有日销记录，先运行原有日销导入，再回填明细。旧版日报缺少这些字段时，常规日销导入会保留已回填的值。结构变更对应 Alembic `20261123_0089`。

要单独刷新已有日销业务字段，在 `extract`、`check`、`apply` 三个子命令上都加 `--fields base`，并使用同一个暂存目录。`extract` 可通过 `--date-start` 和 `--date-end` 限定报表日期。该模式先核对当天 Excel 与数据库的键完全对应，再写入有差异的原字段并逐行复核，保留前述 16 个扩展字段。日期、商品 ID 与尺码 ID 用来匹配记录。
