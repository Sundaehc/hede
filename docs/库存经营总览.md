# 存：库存经营总览

入口：**存 → 库存经营总览**（`/stock-alerts/overview`），默认千百度女鞋。查看沿用 `product.view`；退出规则和分配待办需同时有 `product.view`、`product.manage`。商品档案、库存、采购单及渠道定价不由本页修改。

## 整盘库存与建议

- 以当前聚水潭全量快照的**正可售库存**为库存分布统计范围，复用跨品牌商品与尺码匹配规则。无法唯一关联的来源编码不强行归属；负库存进入待核对。按款色只归入一个状态；「待清货」分组显示这些款色的全部正可售库存，建议实际处理双数以清单为准。「尺码不均衡」表示核心码偏紧而其他尺码仍有库存，不能视为全部为滞销尾码。
- 销量使用已唯一匹配的聚水潭、唯品合并日汇总，按最近 7/30 个自然日分别统计非清仓净销和清仓净销。每个窗口分别确认两份原始日销和品牌日汇总日期覆盖。覆盖天数为正可售库存 ÷ 近 30 天日均总净销；库存与销量匹配不完整、库存日期与日销未对齐或净销非正时不计算。覆盖估算不是历史库存周转率，也不是健康分。
- 为避免过期数据直接派活，建议要求库存已同步至北京时间今天，销售截至昨天。缺档案、缺日销、负可售库存或生命周期数据未对齐时，给出待核对原因。新品零动销继承现有季节/品牌阈值，并核对两份原始日销，避免把同日售出后全退回认作从未动销。档案上市日不是平台上架日。
- 近 7 天和 30 天非清仓净销均大于零时，低售罄老款不因年款自动退出。核心补码沿用交期、备货天数和尺码配比，以最高权重尺码作为一期核心码；只对快照明确存在且库存不足以覆盖交期的核心码提示复核。补码量按非清仓需求计算，不抵扣无到货时间的在途，不代表达到起订量或可以直接下单；起订量在现有「补货建议」核对。

## 退出规则

管理员按**品牌 + 款式年份 + 季节**设置再次开售日（可选）、计划退出日、提前处理天数、目标参考售罄率和清货渠道。首次不自动启用退出规则。「再次开售日」之前标为跨季待售，即使已进入提前处理窗口也不清货；规则保存执行版本核对。

进入退出窗口后，目标为 100% 时按清完当前可售库存判断；低于 100% 时，以 `向上取整(累计正向采购入库 × 目标率) - 累计净销` 估计达标缺口，并约束在 0 到当前可售量之间。预计正常净销取 7/30 天非清仓日均的较低非负值乘剩余天数。扣除预计正常净销后，按尺码保留量、供应商配比和现货分配建议清货量，优先低权重尺码。清货依据不足、数量冲突时转人工复核。采购退货资料不全时历史售罄仍为参考值；首入和最近入库不代表任何一双鞋的实际库龄。配置退出期内不再建议新补货，且待办层拒绝生成同一款色相反的在途决策。

## 待办和复盘

- 系统按清货、零动销、核心补码、低售罄、待核对排序；同类先看期限和影响量。候选按当前数据计算，无需另启后台定时任务。分配前由服务端重新计算并检查依据，已变化时提示刷新。相同品牌、款色、类型共享一条未完成待办；持续存在的建议显示原负责人和期限，实时依据与创建时的审计快照均可查。
- 上周指北京时区上一个完整自然周（周一至周日）。展示当周新增、完成、周末已到期未完成；以周内完成款色去重计算周净销，清仓净销限完成清货待办的款色；库存变化取上周日减前一周日尺码快照，任一快照缺款则不展示合计。经营观察是整个自然周的数，不能视为待办造成的增量；清货回收金额待财务口径提供后接入。
- 阶梯清货价格、库存健康综合分、准确批次库龄、自动降价或下采购单不属于一期。

## 启用与验证

依现有项目方式重新构建前端、由负责人部署并启动后端。后端启动会补建 `stock_overview_exit_policies` 并扩展 PostgreSQL 预警待办的类型约束，以兼容原待办和新补码／清货待办。部署后先配置千百度女鞋的试点季节规则，并用运营确认过的正常老款、跨季款、尺码不均衡和清货样本复核。建议查询不修改业务来源数据。


## 查询性能

- 总览在同一个只读事务内计算近期销量和生命周期。复用一次全品牌档案匹配、同一库存快照的尺码聚合和日销日期覆盖；库存滞后时仍保留两个业务截止日。7/30 天渠道销量在数据库按款色聚合，避免逐日明细回传。新品零动销仍核对聚水潭和唯品原始日销。
- 服务端按品牌和北京时间业务日缓存来源与整盘建议，保存期 120 秒，压缩后合计上限 8 MiB、最多四个品牌日期组合。翻页、筛选及搜索复用计算；依然读取当前规则和待办。规则变化用现有来源重新计算，手动刷新重新读取来源。无需新增索引或迁移。
- 隔离 PostgreSQL 模拟 2 万款、10 万库存行、15 万销量汇总行：对照分开读取与合并读取，首次查询中位数约从 2.49 秒降到 1.96 秒（49 条 SQL 降至 31 条）；复用建议计算中位数约 0.10 秒，未重读库存或销量。此为服务端数据计算采样，不含权限、实时规则及待办查询、网络或浏览器渲染，不能视作正式环境耗时。
