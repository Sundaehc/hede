# 通用回归验收清单

版本：1.3

更新日期：2026-11-06

规范依据：[模块开发规则与 UI 规范](项目开发规则与UI规范.md)、[模块集成约定](模块集成约定.md)。填写方式见[适配模板](项目规范适配模板.md)。

本文用于独立开发及最终集成回赫德主项目的验收。模块补齐真实入口、主项目数据与权限口径；以下为场景，不代表任何模块已通过验证。GEN-01 至 GEN-12 按实际功能选用，GEN-13 为最终集成必验项。

## 执行方式

1. 根据修改范围选择适用场景，记录项目、代码／规范版本、执行人、环境及时区；不适用项说明依据。
2. 按项目适配说明准备隔离数据及测试账号，使用合成输入；不将清表、重建或大数据量验证指向正式环境。
3. 将表中“业务范围 A／B、记录、状态、任务”等替换为本项目对象，补充实际接口／页面步骤及明确预期；仅有场景名称不足以复验。
4. 在开发任务或交付记录中填写通过、失败、未执行或不适用，附实际命令、输入规则和限制。长期场景及用例可由团队取得，临时诊断产物按本项目约定保存。
5. 分开记录独立环境和主项目集成环境的结果；只有独立运行结果时标记“待集成”，不能填写整体交付完成。

## 通用场景

| ID／能力 | 合成输入与执行步骤 | 验收预期 |
|---|---|---|
| GEN-01 环境与启动 | 按适配说明在新环境安装配置；核对实际数据库、API 目标和目录。需要并行应用时，以各自身份登录并操作 | 命令及配置入口可重复使用，初始化写入已说明；无正式数据或文件误写，端口、输出和会话相互隔离 |
| GEN-02 身份与权限 | 分别使用有权、无权及未登录身份，尝试页面及直接接口的读取、修改、导出和敏感字段访问；覆盖另一业务范围对象 | 服务端核验身份、动作及对象范围，无权不能靠手工请求绕过；部门权限以本项目矩阵为准 |
| GEN-03 稳定标识与边界 | 在业务范围 A／B 建相同显示编码、不同稳定 ID 的记录；选择、修改、关联及导出其中之一。另准备缺失和有歧义的关联 | 引用目标记录，不跨范围借值，不凭姓名或显示编码误合并；缺项和歧义按本项目维护流程处理 |
| GEN-04 筛选、分页与选择 | 至少两页、多条件数据；修改条件但不查询，随后提交多选、换页、清空、跨页选择及导出。人为使旧请求延迟返回 | 未提交条件不改变结果；列表、合计、导出同口径；选择范围清楚；过期响应不覆盖新查询 |
| GEN-05 数据与统计 | 包含日期起止边界、零与空值、有效／无效／删除记录，使用可手工算出的最小明细。更新明细后查列表、卡片、详情和导出 | 与本项目记录的来源、公式、状态和分组一致；合计不冒充当前页小计，零和未知不同，失败不显示伪零值 |
| GEN-06 详情、缓存与会话 | 列表加载后更改源记录，再开详情；执行主动刷新、跳转返回、浏览器刷新、退出和切换账号，模拟查询失败 | 详情与缓存按约定失效，不将旧对象当最新；会话恢复与清理符合适配说明，不泄漏另一账户数据 |
| GEN-07 表单与状态变更 | 合法输入、非法数值／日期及未知选项；允许和不允许的状态迁移；普通账号直接尝试越权推进 | 写入前校验，服务端决定状态及权限；必要业务数据和历史符合事务约定；错误保留输入并指明处理方式 |
| GEN-08 幂等与并发 | 同一幂等范围重复请求、相同键更换内容、新键重复业务记录；两个会话基于同一旧版本同时修改 | 不重复产生业务记录，内容及业务冲突明确；过期修改不静默覆盖，用户草稿可保留；失败无未声明的部分写入 |
| GEN-09 导入与资源 | 若适用，准备正确模板、格式不符、关联缺项、重复及多批次合成数据；分别预检与正式导入，观察解析至写入的资源 | 校验一致、覆盖策略和失败影响明确；按本项目上限拒绝；批量及事务符合说明；记录内存峰值和未覆盖规模 |
| GEN-10 后台及调度 | 若适用，启动任务后断网并核验同一任务；覆盖明确失败、同任务重复提交及实际支持的取消／重启行为；核对调度时区和重试 | 断网不直接等于失败，不自动重复创建；状态归属及核验清楚；互斥、幂等和保留范围符合实际计划，不承诺未实现恢复 |
| GEN-11 导出与文件 | 若适用，分别导出筛选、勾选及全量范围，包含带前导零的编码、空值、长表头及无权字段 | 数据范围及字段权限与页面契约一致；编码、格式和缺失值正确；不泄漏已删除、排除或其他范围数据 |
| GEN-12 UI 与可访问性 | 检查项目主题、小屏到桌面、键盘、中文输入法、长文本、下拉与弹窗滚动；覆盖加载、空数据、失败、成功及部分错误列表 | 组件、字体和层级一致，操作可达，焦点及对比度达标；状态和维护建议清楚，编码复制反馈与实际范围一致 |
| GEN-13 主项目最终集成 | 在主项目隔离环境按映射接入模块，执行迁移、主账号登录、菜单／URL、类型检查及必要构建；覆盖无权访问、数据引用、完整业务路径和受影响已有功能，检查测试外壳及身份清理 | 模块在主应用结构中可用，UI 与会话一致，无重复根布局／Provider、账号或正式档案；路由权限及迁移有效，既有口径保持一致；依赖、配置、发布及回退资料齐全；独立运行记录不能替代本项 |

## 记录模板

| 字段 | 本次填写内容 |
|---|---|
| 项目及版本 | [项目名、代码版本、通用规范版本、适配说明版本] |
| 环境及执行人 | [隔离环境标识、执行人、日期及时区；不填连接串] |
| 集成阶段 | [独立开发／主项目集成、采用的主项目代码版本、GEN-13 结果及待处理项] |
| 场景及范围 | [选取 ID、本项目具体对象、未执行／不适用的原因] |
| 输入及实际步骤 | [合成数据构造、接口或页面入口、请求内容及执行顺序] |
| 明确预期 | [本项目公式、权限、状态及影响数量等可核对结果] |
| 实际结果 | [通过／失败／未执行／不适用，实际值及差异] |
| 命令与限制 | [实际命令、结果数量、已知失败及未覆盖能力] |
| 处理与复验 | [任务链接、负责角色、修复和再次核验结果] |

维护时保留场景及合成输入规则，不把一次通过写成长期能力保证。实际自动化命令及长期样本位置由各项目适配说明提供，本清单不依赖参考项目的本机测试文件。
