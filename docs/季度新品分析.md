# 季度新品分析

入口：存 → 季度新品分析，地址 `/stock-alerts/seasonal-analysis`。读取权限沿用 `product.view`，所有查询只读，不新建表或定时任务，不自动分配待办、不修改库存或采购单。

## 新品范围与筛选

按商品档案的有效上市日期归入自然季度（1–3月、4–6月、7–9月、10–12月），统计单位是档案款色，不把尺码算成款数。独立支持品牌、上市年份、季度、商品季节及货号／原始货号／品名／颜色搜索。筛选草稿点击查询后生效；季度、明细状态及页码按账户保留。已售罄商品仍纳入，缺上市日期不猜测归季并提示数量。年份选项来自该品牌已有上市日期。

## 指标

| 指标 | 第一版口径 |
| --- | --- |
| 季度新品 | 所选季度上市且截至北京时间业务昨日已上市的档案款色数。日销落后不减少已上市款色数。 |
| 季度进货 | 本季新品在该季度截至统计日的已入库、正数量、采购候选入库双数。与商品全年累计入库分开。 |
| 新品销售占比 | 该季新品上市后在该季的销售双数 ÷ 同品牌同期已匹配档案的销售双数。为数量占比，不是销售额占比。 |
| 销售／净销 | 复用渠道日汇总的正向销售 `gross_quantity` 和净销 `quantity`。唯品与聚水潭按已有日汇总规则去重；唯品未单列退货。 |
| 整体参考售罄率 | 先合计新品净销量及截至该季统计日的累计正向入库，再相除；不是单品比率平均。包含上市前备货及补货，未完整扣采购退货。缺采购参考或完整日销时不强算。 |
| 前3／7／15天动销率 | 上市当日起前N个自然日中出现正向销售的款色数 ÷ 已满N天且该段日销完整的款色数。观察可跨季度、跨年，最长读取次年1月14日。全额退回不抹去曾经动销的事实；未满期及待核对数量独立显示。 |
| 仅首单／有补货记录 | 已导入来源范围内截至统计日的唯一非空采购单号为1个／多个。同一采购单分批入库仍算一个；缺采购单号或无有效入库不判为首单。拆单、合单和历史覆盖不足可能影响判断，并非实物批次判断。 |
| 入库日期 | 取采购候选入库记录的 `inbound_date`，按商品款色汇总截至所选季度统计日的全部历史入库日期，包含上市前备货。同一天合并，日期倒序展示；默认显示最近两个日期，其余可展开。与文件导入时间无关；无记录与来源未就绪分别提示。 |
| 当前可售库存 | 最新全量库存快照，缺记录显示“—”，显式零库存显示0。与过去季度销售并列时不声称是历史季末库存。 |

跨季度表比较同一上市年份的四个新品群组。每季自身销量和售罄按该季末或日销截止日计算；“所选季度净销”将各批新品放到同一所选季度观察，体现跨季销售。不同季度累计观察时间不同，不能直接当相同观察期的选品考核。

明细筛选只切换清单，不改变上方整盘汇总。商品搜索及季节筛选在汇总前应用；销售占比分母保留整品牌同期范围，翻页不重算成当前页占比。

## 数据来源和限制

- 商品来自各品牌有效档案，沿用默认条码构成及尺码组；库存和采购匹配使用现有 `ArchiveMatcher`，跨品牌或同码歧义不任意关联。
- 销量来自 `factory_channel_sales_daily_summaries` 中该品牌 `matched` 记录；`unmatched` 在现有汇总中不代表可信品牌归属，不进入品牌分母。`duplicate_vip` 不再重复累计。
- 日销截止取北京时间业务昨日、聚水潭及唯品最新销售日中的最早值；逐日核对两份日销和品牌汇总日期标记，缺日显示未知，不能视作销量0。
- 季度品牌销量统计需要整个季度截至统计日完整。单品销售只要求自身上市日起完整；动销率只要求自己的观察窗口完整。
- 新增或改号商品需等待既有渠道日汇总重新生成，页面刷新不重建历史汇总。动态品牌如无品牌汇总日期标记，会提示待核对。
- 库存和采购参考先按本年新品的货号、原始货号、条码构成及尺码生成候选编码，筛选后仍用全品牌匹配器拒绝歧义；页面库存未匹配数量统计本年新品及本年首次入库且无有效上市日期的候选范围，不再为该提示扫描全品牌库存。采购先从 `mv_jst_purchase_inbound_age_reference` 确认可唯一关联的商品编码，再按编码索引分批读取 `v_jst_purchase_inbound_age_candidates`，按季度、采购单号聚合。已完成来源、正向采购候选的定义沿用[采购入库历史与库龄参考](采购入库历史与库龄参考-2026-10-27.md)。
- 没有接入真实入库批次消耗、完整采购退货或平台结算，不将参考售罄率用作准确批次剩余量或财务结算指标。

## 性能与验证

首次查询将品牌销量分母按日直接在数据库汇总，仅传输年度新品及重码核对需要的商品日销；品牌日销日期标记使用按天索引存在性查询。其他品牌档案只读匹配身份所需字段，库存和采购参考在数据库筛选候选编码。

后端按引擎、品牌、年份及北京时间业务日缓存120秒，最多4项／8 MiB；使用构建锁、只读可重复读事务、25秒单SQL超时、5000行流式读取及1000编码一批采购查询。分页、季节和关键词变化复用年度事实。前端沿用存模块按账户隔离的有界缓存、请求合并和失效通知；手动刷新绕过事实缓存，切换时保留上一结果并标注正在更新。

实现：`backend/domain/seasonal_analysis.py`、`backend/storage/seasonal_analysis_facts.py`、`GET /stock-alerts/seasonal-analysis`、`frontend/components/stock-alerts/seasonal-analysis-page.tsx`。

后端合成测试保存在本地 `outputs/logs/test_seasonal_analysis.py`，不上传 `backend/tests`。覆盖观察期边界、全退回、缺日、跨季窗口、首单去重、缺采购、歧义、分页和筛选。前端验证草稿、翻页、刷新、季度切换及未知值显示。正式库仅做只读试算；未启停业务后端，新增接口需负责人手动重启后端后生效。

## 到货跟进与单款复盘

- **到货待补上市日期**：按已导入的首次正向采购入库日期归季，要求当前有可售库存，档案上市日期缺失或无效。该清单不依赖日销，也不计入季度新品指标。
- **上市满 15 天零动销**：季内上市至统计日相差至少 15 天、日销逐日完整且仍有可售库存。先查渠道日汇总，再用原始聚水潭和唯品日销排除遗漏的正向销售，例如聚水潭同日售出后全退回。缺失销量、商品关联存在已知歧义时，不认定为确认零动销。
- 点击商品货号或「本季进货」双数打开单款复盘，查看首次采购入库、档案上市、观察期内首销、各渠道销售／净销和当前可售库存。正常款按上市日至该季统计日查询；无有效上市日期的款从首次入库开始观察。日销缺日不显示完整渠道合计；首销日期之前有数据断档时，不给出确定首销日期。渠道明细直接读取聚水潭与唯品日销，复用店铺渠道映射及同款同日唯品去重；原始记录中的正向销售可能多于既有季度汇总。
- 本季采购入库沿用正向采购候选。按日期、入仓单号、采购单号汇总同款各尺码，逐笔分页，并列出全季合计。已上市款使用该季日销截止日；待补上市日期款使用业务日或季末，以先到者为准。入仓／采购单号沿用 `inventory.view` 权限，缺号如实显示；不返回单价和供应商。复盘按需只读查询，不在初次列表查询时加载每款单据。

零动销原始日销仅在打开该清单时核对，范围限定在所选季度。千百度男鞋 2026 年第四季度以 2026-11-17 日销及 2026-11-18 库存只读抽查：3 款符合零动销，待补上市日期 0 款；`C7764168M02` 3 笔合计 60 双，`C5562415DA24` 13 笔合计 14 双，均与本季进货列一致。
