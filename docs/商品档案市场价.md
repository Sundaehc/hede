# 笑脸和 NI 商品档案市场价

更新日期：2026-11-18。

商品信息档案的笑脸（`smiley`）和 NI（`ni`）新增“市场价”，位于“物价信息”中，可在新增、编辑时维护，并在商品卡片和详情显示。其他品牌不展示此字段。市场价独立于工厂出货价、成本价，没有成本查看权限的用户仍可查看市场价。

字段允许留空或填写零，最大值为 `99999999.99`，最多两位小数。编辑时清空可删除原价格；API 更新未传 `market_price` 时保留旧值，显式传 `null` 时清空。非法金额拒绝保存，不能静默四舍五入。

## Excel 与来源同步

- 通用导入模板包含选填的“市场价”，也兼容“吊牌价”和 `market_price` 表头，仅对笑脸和 NI 生效。
- Excel 空白单元格保留已有价格；零是有效价格。非法金额提示源行号，并回滚本次导入。
- 笑脸、NI 的标准档案导出包含市场价；全部品牌导出包含统一市场价列，其他品牌该列为空。成本查看权限不影响市场价导出。
- 每日来源同步、档案替换／增量写入及 NI 桌面档案导入保留已有市场价，避免来源缺少该字段时清空人工维护值。
- 新字段不自动从笑脸精细表或其他价格表回填；旧档案在首次维护前为空。

## 结构与启用

仅 `smiley_products` 和 `ni_products` 增加可空 `NUMERIC(10,2)` 字段 `market_price`，无默认值。迁移为 [20261118_0087_product_market_price.py](../backend/alembic/versions/20261118_0087_product_market_price.py)，后端及导入任务初始化也会兼容补列。原数据库结构快照不修改。

按[项目约定](赫德项目规范适配说明.md)，业务后端由负责人手动启停。更新前后端代码后，由负责人手动重启后端，前端按当前部署方式重新加载或构建后刷新页面。本次开发仅使用隔离测试库，没有对业务数据库执行迁移或回填。

## 复验场景与本次验证

在隔离环境对两个品牌分别执行：新增 `199.90`、重新打开、改为 `0`、改为其他价格、清空并重新打开；负数、三位有效小数、超上限及非数字均须拒绝。其他品牌无市场价输入项。

导入含市场价／吊牌价的文件，确认金额落库；导入空白和零分别保留旧值、保存零。两行文件第一行合法、第二行非法时，验证整批回滚且错误行号正确。重复执行来源同步，维护的价格不丢失。

同时检查两个品牌及全部品牌的查询、标准 Excel 导出，以及客服／美工成本隐藏情形：价格应只展示一次，零不能变为空，成本继续隐藏；其他品牌全部导出的市场价单元格为空。检查迁移重复执行、旧行空值和其他品牌表结构不变。
