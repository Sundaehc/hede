# 原始货号映射每日更新

- Windows 计划任务：`HedeImportOriginalSkuSummaryDaily`。
- 每日北京时间（UTC+8）03:00执行，首次计划为2026-10-29 03:00。失败每30分钟重试，最多6次；当天成功后不再重复更新。不依赖后端HTTP服务运行。
- 源文件：`\\192.168.10.229\运营组资料\9商品组（卢嘉诚）\货号汇总新.xlsx`。
- 仅读取“原始货号汇总”工作表的A列“货号”和B列“原始货号”。不读取其他列或工作表的数据入库，不要求源文件必须在当天修改。
- 写入`public.product_sku_mappings`：`sku`为货号，`original_sku`为原始货号。新增货号、更新已有货号的映射；源文件移除的货号保留，不自动删除。
- 完全重复的货号映射去重；同一货号对应多个不同原始货号、缺列、缺值、Excel错误值或读取过程中源文件变化，均整次失败，不部分发布。前导零按文本保留。
- 读取文件完成后，在单一数据库事务中暂存、更新并逐条核对。失败回滚，保留上一版映射；任务与导入均有互斥锁，避免并发执行。
- 业务结果写入`scheduled_task_statuses`，执行记录写入`scheduled_task_runs`，文件日志为`E:\hede\backend\logs\import_original_sku_summary_daily.log`。
- 复用已有共享文件导入任务的Administrator交互登录账号。电脑须开机、网络和数据库可用，并保持该账号登录（可以锁屏，注销后不能运行）。错过计划时在条件允许后补跑。若需要注销后仍运行，需另配置有共享目录权限的后台账号及凭据。

## 管理命令

```powershell
Get-ScheduledTask -TaskName HedeImportOriginalSkuSummaryDaily | Get-ScheduledTaskInfo
schtasks /Run /TN HedeImportOriginalSkuSummaryDaily
```

注册入口为`backend/scripts/configure_original_sku_summary_daily_task.ps1`，重复注册会拒绝覆盖已有任务。`scripts/`、`tests/`仍按用户要求忽略，不提交Git；新机器部署时需要另外保留本机任务脚本和XML备份。任务XML备份位于`backend/logs/scheduled-task-backups/`。
