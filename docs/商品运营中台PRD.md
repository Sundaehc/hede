| 项目 | 内容 |

| 产品名称 | 赫德商品运营中台 |

| 产品定位 | 面向多品牌、多平台商品经营的商品主数据、采购、进销存与权限管理系统 |

## 1. 产品概述

### 1.1 建设背景

商品资料、采购单、库存单据、供应商和仓库信息长期分散在 Excel、聚水潭、管家婆及共享文件夹中，导致重复录入、数据口径不一致、单据追溯困难。系统需要以商品档案为核心，连接采购与进销存业务，并通过精细表、货品表支撑商品运营决策。

### 1.2 产品目标

1. 建立多品牌统一、可追溯的商品主数据。
2. 将采购订单、入退货、调拨、损益、批发和往来单据在线化管理。
3. 以货号、款号、颜色、尺码为颗粒度查看商品销售、库存、在途和补单数据。
4. 提供标准化导入导出、图片服务、权限控制和操作日志能力。
5. 让商品、采购、运营、仓储、财务在同一系统中使用一致的基础资料和业务单据。

### 1.3 适用范围

- 品牌：千百度男鞋、千百度女鞋、烟斗、伊伴，以及后续可配置品牌。
- 业务组织：商品部、开发部、运营部、采购/供应链、仓储、财务、视觉和管理人员。
- 业务平台：商品档案、采购单管理、进销存管理、系统管理。

### 1.4 非目标

1. 不替代聚水潭、管家婆等外部 ERP 的全部原生能力。
2. 不在未审批的情况下自动修改采购数量、库存、成本或财务数据。
3. 不将平台后台高风险操作作为一期必需能力，优先处理数据同步与业务单据管理。

## 3. 用户角色与权限

| 角色 | 主要使用模块 | 核心权限 |
| --- | --- | --- |
| 超级管理员 | 全部模块 | 用户、角色、部门、权限、全局日志和数据管理 |
| 商品/开发人员 | 商品档案、采购单、货品表 | 商品维护、采购单创建与编辑、商品分析查看 |
| 平台运营人员 | 商品档案、精细表、货品表 | 商品资料查看、经营数据查看、按授权编辑运营字段 |
| 采购/供应链人员 | 采购单、进销存、供应商、仓库 | 采购单、入库/调拨/损益单据维护 |
| 财务人员 | 进销存、一般客户、科目、供应商 | 往来单据、科目、对账辅助和导出 |
| 视觉人员 | 商品信息档案 | 商品资料、图片查看与按授权维护 |
| 普通查看人员 | 授权模块 | 只读、搜索、筛选和导出 |

### 3.1 权限规则

1. 导航仅展示用户具有查看权限的模块。
2. 新增、编辑、删除、导入、导出、审批及操作日志查看独立授权。
3. 商品货品表属于经营敏感数据，默认仅对商品相关岗位及超级管理员开放，具体部门范围可配置。
4. 成本、采购价、财务往来、利润等敏感字段按最小权限原则展示。
5. 删除采用回收站机制；业务单据在回收站保留 10 天后可自动清理，恢复与彻底删除需授权。

## 4. 公共能力

### 4.1 品牌与主数据

1. 所有商品、采购单与进销存单据必须关联品牌。
2. 商品主键优先使用完整货号/SKU；款号、颜色、尺码、工厂货号作为关联和分析维度。
3. 品牌、供应商、仓库、一般客户、会计科目等基础资料在引用处通过下拉或搜索选择，避免自由文本造成重复。

### 4.2 搜索、筛选、排序与分页

1. 列表支持关键词搜索、时间范围、品牌、业务类型、状态等组合筛选。
2. 商品精细表和货品表支持表头筛选、排序、完整视图与自定义列视图。
3. 大数据列表使用服务端分页、缓存和预取；筛选条件应可清空、可回显。

### 4.3 导入、导出与图片

1. 支持 Excel 导入模板下载、字段校验、错误行提示、覆盖导入确认和导入结果汇总。
2. 支持按当前筛选条件导出；大数据导出应显示进度并避免阻塞页面。
3. 商品图片可按货号自动匹配共享目录图片；缩略图支持点击预览原图。

### 4.4 审计与异常处理

1. 新增、编辑、删除、导入、导出、恢复等操作写入操作日志。
2. 日志至少记录模块、操作人、时间、对象、变更摘要和结果。
3. 导入、同步、导出或图片匹配失败时应返回可理解的错误原因和可重试入口。

## 5. 商品档案模块

### 5.1 模块目标

统一管理商品基础资料、商品经营明细和货品经营指标，为采购、上架、库存、补单及渠道运营提供可信商品数据。

### 5.2 商品信息档案

#### 5.2.1 核心功能

| 功能 | 需求说明 |
| --- | --- |
| 品牌切换 | 支持按品牌查看商品；总览可跨品牌检索与查看。 |
| 商品列表 | 展示商品图片、货号、款号、颜色、年份、季节、工厂、成本、材质等基础字段。 |
| 搜索 | 支持单个或批量货号/款号搜索，兼容逗号和换行分隔。 |
| 新增与编辑 | 使用弹窗维护商品信息；字段分组展示，日期、季节、品牌等使用标准控件。 |
| 图片匹配 | 根据货号从品牌图片目录匹配图片，显示匹配状态并支持原图预览。 |
| 导入导出 | Excel 导入按货号优先匹配、款号辅助匹配；仅覆盖导入文件中存在且有效的字段。 |
| 批量操作 | 支持勾选、批量删除和导出；删除前二次确认。 |
| 操作日志 | 可查看商品新增、编辑、导入、导出、删除等记录。 |

#### 5.2.2 关键字段

基础字段包括但不限于：品牌、货号、款号、原始款号、颜色、年份、季节、品类、工厂货号、工厂名称、工厂代码、成本、材料、鞋盒类型、卖点、上市/首单时间、图片路径、备注及扩展字段。

#### 5.2.3 业务规则

1. 同一品牌内货号必须唯一；导入时重复货号以最后一条有效记录为准并提示重复情况。
2. 空字符串写库前统一转换为空值，避免数值、日期字段写入异常。
3. 导入只覆盖有值字段，防止空白模板覆盖历史有效数据。
4. 新增/编辑商品后，相关图片、精细表和货品表在下一次刷新或同步后展示最新资料。

#### 5.2.4 验收标准

1. 可在 3 秒内完成常规品牌商品分页查询。
2. 批量搜索可准确返回输入货号/款号对应商品。
3. 导入结果包含成功数、失败数、失败原因和可定位行号。
4. 图片存在时可预览原图，图片缺失时明确提示。

### 5.3 商品精细表

#### 5.3.1 模块定位

面向商品、运营和管理人员的“商品全字段分析表”，以商品基础资料叠加库存、销售、价格、平台与运营字段，支持按日期查看历史快照。

#### 5.3.2 核心功能

1. 按品牌、日期、货号、款号、工厂、品类、平台等筛选和排序。
2. 支持完整视图、自定义列视图、列分组和表头筛选。
3. 展示商品资料、图片、成本、库存、销售、运营、尺码及平台指标。
4. 支持历史日期快照查询，当前数据与历史数据的日期范围需明确展示。
5. 支持详情侧栏/弹窗查看完整字段、原图及手动维护的运营字段。
6. 支持当前页与全量导出，导出字段遵循当前视图和筛选条件。
7. 支持缓存、分页、邻页预取和操作日志，保障大表使用体验。

#### 5.3.3 验收标准

1. 历史日期选择后能加载对应快照或明确提示数据不存在。
2. 自定义列、筛选、排序和导出结果保持一致。
3. 图片、成本、库存等字段可追溯数据来源或更新时间。

### 5.4 商品货品表

#### 5.4.1 模块定位

面向商品与经营决策的货号/SKU 经营表，重点呈现销售、库存、在途、尺码、补单、断码和平台经营数据。

#### 5.4.2 视图与核心能力

| 视图/能力 | 需求说明 |
| --- | --- |
| 货号明细 | 按完整货号展示颜色、尺码、库存、销量、补单、平台分渠道数据。 |
| 款号汇总 | 去除末尾颜色编码后按款号汇总销量、库存、在途、缺货和补单数据。 |
| 缺货风险 | 聚焦在仓、在途、建议补单、尺码断码和库存健康度，支持快速处理。 |
| 时间维度 | 支持当前数据和历史快照按日期查看。 |
| 尺码维度 | 支持按 34-44 等尺码展示在仓、在途、库存合计、缺货、销售与补单明细。 |
| 平台维度 | 支持唯品、天猫、得物、拼多多、京东、商品卡、直播赛道、达播清仓、拼多多清仓、其他等日/周/月销量。 |
| 手动字段 | 所属平台、四级分类、商品角色、类型、抖音爆款、清仓、备注以及补单相关字段可在详情中按权限维护。 |
| 导出 | 支持当前页、全量、货号明细与款号汇总导出。 |

#### 5.4.3 核心展示字段

1. 基础：年份、季节、所属平台、四级分类、首单日期、工厂货号/代码/名称、款号、货号、颜色、图片、成本、商品角色、类型、抖音爆款、清仓、备注。
2. 经营：总订单量、总销量、昨日销量、昨比前日、近 7 天、上周、同期周销、年度销量、月度销量。
3. 库存：在仓+进货仓、在途、库存合计、缺货库存、库存健康度、断码 SKU、按尺码明细及合计。
4. 补单：补单明细/合计、补单后尺码/库存/合计、补单后周转天数。
5. 平台：各平台日销量、周销量、月销量及近 14 天逐日销量。

#### 5.4.4 数据规则

1. 销售以聚水潭日销、唯品日销及历史销售表为主要来源；渠道按店铺映射与 `channel` 规则归类。
2. 在仓库存为仓库库存与进货仓库存之和；在途库存来自采购/调拨在途字段；缺货库存根据可用库存为负的尺码计算。
3. 款号汇总以原始款号/货号去除末尾颜色编码后聚合，金额、销量、库存、在途和尺码数据按同款下 SKU 汇总。
4. 快照查询优先使用对应日期的货品表快照；当前数据使用最新库存、销售和手动字段计算。
5. 货品表手动编辑仅修改运营覆盖字段或补单字段，不覆盖商品档案和 ERP 来源字段。

#### 5.4.5 验收标准

1. 品牌、视图、日期、筛选、排序切换无明显页面抖动。
2. 货号明细、款号汇总和导出数据口径一致。
3. 筛选弹层、详情、图片预览、分页和导出在大数据量下可正常使用。
4. 无权限用户不可见货品表导航、接口和操作日志。

## 6. 采购单管理模块

### 6.1 模块目标

在线创建、导入、审核、导出和追踪采购订单，将商品、供应商、仓库、交期、尺码明细和生产要求关联为可追溯采购单。

### 6.2 核心功能

| 功能 | 需求说明 |
| --- | --- |
| 采购单列表 | 单独展示单据类型为“进货订单”的记录，支持待完成/已完成、品牌、供应商、仓库、日期、交期、经手人、摘要筛选。 |
| 新增/编辑采购单 | 维护订货日期、供应商、仓库、经手人、交货日期、摘要、品牌与单据明细。 |
| 商品明细 | 明细使用完整商品编码，展示商品名称、颜色规格、尺码、数量、单价、金额、备注和图片。 |
| Excel 导入 | 下载采购单模板，按采购单备注/摘要分组建单；导入前校验供应商、日期、交期、仓库、经手人、商品编码和数量。 |
| 采购单导出 | 支持汇总、尺码行和生产采购单格式导出；生产采购单按品牌套用对应的条款/生产要求。 |
| 状态管理 | 支持未完成、已完成、删除/回收站状态；完成状态用于后续入库或交货跟踪。 |
| 操作日志 | 记录采购单及明细的新增、编辑、导入、导出、删除和恢复。 |

### 6.3 业务规则

1. 采购单的单据类型固定为“进货订单”。
2. 采购单必须填写订货日期、供应商、仓库、经手人、交货日期和摘要。
3. 商品编码应为带颜色和尺码的完整编码；系统解析并匹配商品与单价，不能匹配时进入错误明细。
4. 单据金额由明细数量与单价汇总，明细变更后自动重算。
5. 不同品牌导出生产采购单时加载对应品牌条款；无配置品牌使用默认模板并提示维护。

### 6.4 验收标准

1. 可完成单张采购单的新增、编辑、明细维护、导入、导出和恢复。
2. 导入模板字段缺失、商品编码无效、数量非法时阻止提交并提示具体原因。
3. 采购单导出金额、数量、尺码明细与页面一致。

## 7. 进销存管理模块

### 7.1 模块目标

通过标准单据和基础资料记录商品流转、库存变动与往来业务，为采购、仓储、销售、财务和经营分析提供可追溯数据。

### 7.2 经营历程

#### 7.2.1 单据类型

1. 进货单、进货退货单。
2. 报溢单、报损单。
3. 批发销售单、批发销售退货单。
4. 同价调拨单。
5. 应付款增加、应付款减少、应收款增加、应收款减少。

#### 7.2.2 核心功能

1. 创建、编辑、查询、筛选、导入、导出、删除、恢复经营单据。
2. 单据头维护日期、类型、供应商/一般客户/出入仓库、经手人、摘要、品牌和备注。
3. 单据明细维护商品编码、商品名称、颜色规格、数量、单价、金额和明细备注。
4. 根据单据类型动态显示对手方、仓库、会计科目及金额字段。
5. 支持查看单据详情、商品图片和单据变更记录。
6. 支持未完成/已完成状态管理与回收站。

#### 7.2.3 业务规则

1. 入库类单据增加库存，出库类单据减少库存；调拨单同时记录出库仓与入库仓。
2. 报溢、报损、批发退货按对应业务类型影响库存与金额。
3. 应收/应付单据属于往来记录，可创建会计明细；不纳入普通商品明细 Excel 导出范围。
4. 单据总数量与总金额由明细自动汇总，禁止手工修改汇总值。

### 7.3 商品进货明细

#### 7.3.1 模块定位

按商品粒度汇总采购/进货明细，帮助商品、采购与财务快速追踪某货号的进货次数、供应商、数量、单价、金额与所属单据。

#### 7.3.2 核心功能

1. 支持按品牌、货号、商品名称、供应商、日期、单据号和仓库筛选。
2. 展示采购单/进货单来源、完整商品编码、商品图片、颜色规格、数量、单价、金额、供应商、仓库、交期和经手人。
3. 支持跳转或打开来源采购单/经营单据详情。
4. 支持导出筛选结果。

### 7.4 供应商管理

功能包括供应商新增、编辑、删除、搜索、导入、导出与操作日志。基础字段包含供应商名称、工厂代码、联系人、联系电话、地址、合作品牌、结算/备注信息。

业务规则：供应商名称需去重；被单据引用的供应商不允许直接物理删除，应提示改为停用或保留历史数据。

### 7.5 仓库管理

功能包括仓库新增、编辑、删除、搜索、导入、导出与操作日志。基础字段包含仓库名称、地址、联系人、联系电话、仓库类型和备注。

业务规则：被历史单据引用的仓库保留历史记录；调拨单必须选择不同的出入仓库。

### 7.6 一般客户

功能包括一般客户品牌和店铺的分层维护：新增、编辑、删除、搜索及操作日志。用于批发销售、销售退货和应收业务选择对手方。

业务规则：客户店铺必须归属一个一般客户品牌；被历史单据引用的记录不可直接物理删除。

### 7.7 科目管理

功能包括应收、应付等往来业务的会计科目维护、启停、搜索及操作日志。

业务规则：科目用于应收/应付单据的明细记录；已被会计明细使用的科目只能停用，不得直接删除。

### 7.8 验收标准

1. 不同单据类型能正确展示必填字段和对手方选择器。
2. 明细增删改后数量、金额及单据详情实时一致。
3. 商品进货明细可追溯到来源单据与供应商。
4. 基础资料的编辑和停用不破坏历史单据展示。

## 8. 系统管理模块

### 8.1 用户管理

#### 8.1.1 核心功能

1. 用户新增、编辑、启用、停用、重置密码与删除。
2. 维护用户名、姓名、部门、角色、账号状态和可访问品牌/模块。
3. 分配角色权限：商品查看/管理、精细表查看、采购查看/管理、进销存查看/管理、系统管理等。
4. 支持查看用户相关的操作日志，超级管理员可查看全局日志。
5. 禁用用户后立即阻止登录和接口访问；历史操作日志保留。

#### 8.1.2 业务规则

1. 用户名唯一；密码按安全规则存储，不展示明文。
2. 超级管理员账号不得被普通管理员停用或删除。
3. 用户权限变更后在下一次请求生效；已登录会话应按安全策略刷新。
4. 超级管理员操作日志不得对普通用户展示。

#### 8.1.3 验收标准

1. 用户仅能看到被授权的导航、页面、按钮和接口数据。
2. 无权限访问 URL 或 API 时返回明确的无权限提示。
3. 用户创建、权限调整、停用和删除均留存审计记录。

## 9. 核心数据对象与关系

```text
品牌
  -> 商品档案（货号/SKU、款号、颜色、尺码、成本、图片）
  -> 商品精细表 / 商品货品表（销售、库存、运营快照）

供应商 + 仓库 + 商品
  -> 采购单（进货订单）
  -> 经营历程（进货、退货、调拨、损益、批发、往来）
  -> 商品进货明细

一般客户 + 会计科目
  -> 批发销售/退货与应收应付单据

用户 + 角色 + 部门
  -> 模块权限 + 操作日志
```

## 10. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 常规列表查询响应目标 3 秒内；大表使用分页、缓存、服务端筛选和异步导出。 |

| 可维护性 | 数据源、品牌、字段映射、单据类型、导入模板与权限规则可配置或版本化。 |

## 11. 迭代计划

### P0：稳定主数据和单据闭环

1. 商品信息档案、采购单、经营历程、基础资料和用户权限的 CRUD、导入导出、日志闭环。
2. 商品精细表与货品表的分页、筛选、自定义列、日期快照和导出。
3. 单据明细与商品图片关联、回收站和数据校验。

### P1：经营协同

1. 采购单交期提醒、到货进度与采购单转入库单辅助。
2. 货品表库存健康、断码、在途、补单和清仓风险提示。
3. 商品档案与平台上架资料、供应商数据和成本数据的自动同步。

### P2：决策与智能化

1. 基于销售、库存、在途和尺码结构的补单建议。
2. 自动日报、周报、经营异常和数据质量告警。
3. 对接 AI 内容、商品资料生成和经营分析能力，所有高风险动作保留审批。

## 12. 待确认事项

1. 各品牌的商品字段、采购条款、尺码规则和成本口径是否需要差异化配置。
2. 采购单审核、完成、入库及作废的审批链路与责任人。
3. 进销存单据是否需要与聚水潭/管家婆双向同步，以及冲突处理规则。
4. 一般客户、供应商和仓库的停用/删除策略及历史数据保留期限。
5. 商品精细表与货品表的数据刷新时间、快照频率、历史保留年限和最终责任部门。
